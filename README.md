## Возможности

- Загрузка статистики из API
- Отображение статистики в виде графиков и диаграм
- Кеширование данных
- Pull-to-refresh для принудительного обновления

---

## Установка и запуск

Чтобы запустить приложение, выполните следующие шаги:

1.  Клонируйте репозиторий:
    ```sh
    git clone https://github.com/ShijaN03/stats-app
    ```
2.  Перейдите в директорию проекта и откройте .xcodeproj:
    ```sh
    cd stats-app
    open StatisticsTestTask.xcodeproj
    ```
3.  Соберите и запустите приложение на симуляторе или реальном устройстве.

## Используемые технологии

- **Swift** — язык
- **UIKit** — UI
- **MVC** — архитектура
- **PinLayout** — верстка
- **RxSwift** — сетевые запросы
- **Realm** — кеширование
- **DGCharts** - графики
